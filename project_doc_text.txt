5.  Context  Mapping:  Xác  định  cách  các  bounded  context  giao  tiếp  với  nhau

·        Tất  cả  →  Notification:  Publish  event  qua  Kafka/RabbitMQ.  
·        Real-time  GPS:  WebSocket  Gateway  +  Redis  Geo.

·        API  Gateway  làm  Policy  Enforcement  Point  (PEP)  cho  Zero  Trust.

4.3   Kiến  trúc  triển  khai  (Deployment  Architecture)  
Hệ  thống  được  triển  khai  theo  mô  hình  cloud-native  trên  Kubernetes  (hoặc  Docker

·        Horizontal  Pod  Autoscaling  (HPA)  tự  động  scale  theo  CPU/Memory  và  
custom

·        Global  Load  Balancer  +  API  Gateway  tại  Edge.  
·     Infrastructure  as  Code:  Terraform  quản  lý  toàn  bộ  tài  nguyên  AWS.  
·     CI/CD:  GitHub  Actions  →  Docker  Build  →  Kubernetes  Deploy.  
4.4.  Kiến  trúc  Real-time  &  Event-driven  
·        Real-time  Layer:  WebSocket  Gateway  (Socket.IO)  kết  nối  trực  tiếp

·     Latency  mục  tiêu:  <  1  giây  cho  GPS  update  và  notification.  
4.5.  Kiến  trúc  AI  &  Intelligent  Services

·     ML  Platform:  Feature  Store  +  Model  Training  +  Model  Serving  API.

·        Service-to-Service:  mTLS  +  Service  Mesh  (Istio/Linkerd).  
·        IAM:  Central  Auth  Service,  JWT  ngắn  hạn  +  Refresh  Token  rotation,  Redis

·        Data  Security:  Encryption  at-rest  &  in-transit,  Secrets  Manager  (HashiCorp

4.7.  Kiến  trúc  mở  rộng  &  chịu  lỗi  (Scalability  &  Resilience)
